## Distribution Formats

### 1. Tauri v2 Desktop App (Primary)
**Platforms:** Windows (.exe + NSIS), macOS (.dmg, universal), Linux (.AppImage + .deb)

```bash
# Install Tauri CLI
cargo install tauri-cli

# Build for current platform
cd mullm
npm run tauri build

# Cross-compile (requires CI/GitHub Actions)
# Windows: windows-latest runner
# macOS: macos-latest runner
# Linux: ubuntu-latest runner
```

**Architecture:**
- Tauri shell (~15MB) wraps the web UI
- Python sidecar runs FastAPI backend on `127.0.0.1:6856`
- Bundled: Python 3.12, uv, core dependencies
- Ollama: downloaded on first run (user's machine) or bundled lite build
- Total bundle: ~150MB without models, ~6GB with qwen3.5:9b

**Sidecar config (`src-tauri/tauri.conf.json`):**
```json
{
  "bundle": {
    "externalBin": ["sidecar/python-sidecar"],
    "resources": ["router/**/*", "config/**/*"]
  }
}
```

### 2. Docker / Podman (Server/Cloud Deploy)
```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY router/ router/
COPY config/ config/
EXPOSE 6856
CMD ["python", "-m", "router.main", "--https"]
```

```bash
# Build
podman build -t mullm:latest .

# Run (GPU passthrough for Ollama)
podman run -d \
  --device nvidia.com/gpu=all \
  -p 6856:6856 \
  -v mullm-data:/app/cache \
  mullm:latest
```

### 3. One-Line Install (Linux/macOS)
```bash
curl -fsSL https://mullm.dev/install.sh | bash
```
Script: installs Python deps, downloads qwen3.5:9b, starts server, opens browser.

### 4. Windows Installer (NSIS via Tauri)
Auto-generated by `tauri build --target x86_64-pc-windows-msvc`
Includes: Python runtime, mullm, Ollama launcher shortcut.

## Voice Walkthrough (British Gentleman)

**Engine:** [Piper TTS](https://github.com/rhasspy/piper) — CPU-only, 50ms latency, no API needed.

**Voice:** `en_GB-alan-medium` — calm, professional British male.

```python
# router/voice.py
import subprocess, tempfile, os

def speak(text: str, voice: str = "en_GB-alan-medium"):
    """Speak text using Piper TTS. Non-blocking."""
    with tempfile.NamedTemporaryFile(suffix=".wav", delete=False) as f:
        wav_path = f.name
    subprocess.run([
        "piper", "--model", f"models/tts/{voice}.onnx",
        "--output_file", wav_path
    ], input=text.encode(), capture_output=True)
    subprocess.Popen(["aplay", wav_path])  # Linux; afplay on macOS; powershell on Windows
```

**Setup wizard integration:**
```javascript
// Each setup step optionally plays audio
async function speak(text) {
  if (!voiceEnabled) return;
  const resp = await fetch('/api/speak', {method:'POST', body: JSON.stringify({text})});
  // Server streams WAV, browser plays via Web Audio API
}
```

Optional bundle task: add a Piper sidecar and expose it through the existing TTS backend registry.

## Observability Export (OTel / Datadog / Splunk / New Relic)

**Already available:** Structured JSON logs (structlog), scoring_log.jsonl, Redis streams.

**1-session add:** OpenTelemetry SDK

```python
# config/otel.py
from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.exporter.otlp.proto.grpc.trace_exporter import OTLPSpanExporter

def setup_otel(endpoint: str = "http://localhost:4317"):
    """Wire OTel traces to any OTLP-compatible backend."""
    provider = TracerProvider()
    provider.add_span_processor(
        BatchSpanProcessor(OTLPSpanExporter(endpoint=endpoint))
    )
    trace.set_tracer_provider(provider)
```

**Every /query call** already has: intent_id, tier, model, latency_ms, cost, tokens, category, complexity. These map directly to OTel span attributes.

**Compatible backends (all via OTLP):**
- Datadog: `OTEL_EXPORTER_OTLP_ENDPOINT=https://api.datadoghq.com/api/intake/otlp/v1/traces`
- New Relic: `https://otlp.nr-data.net:4317`
- Splunk: `https://ingest.<realm>.signalfx.com:443`
- Grafana Tempo: any self-hosted OTLP endpoint
- Custom: any gRPC OTLP receiver

Optional bundle task: expose `OTEL_ENDPOINT` in setup and install the OpenTelemetry extras.

## Private Asset Strip Script

```python
# scripts/strip_private_assets.py
import shutil, os
from pathlib import Path

STRIP = [
    "cache/data/scoring_log.jsonl",
    "<state>/cache/data/semantic_cache.sqlite3",
    "cache/data/chromadb",
    "<state>/cache/data/videos",
    "screenshots",
    "sessions.jsonl",
    ".env",
    "models/routing-classifier",
]

KEEP_GAMES = 10  # ship only N best games

root = Path(".")
for path in STRIP:
    p = root / path
    if p.is_dir():
        shutil.rmtree(p, ignore_errors=True)
    elif p.is_file():
        p.unlink(missing_ok=True)

# Keep only top N games
games = sorted((root / "code/ready").glob("*.html"))
for g in games[KEEP_GAMES:]:
    g.unlink()

print(f"Stripped. Kept {KEEP_GAMES} games.")
```

## MCP + A2A Integration

muLLM exposes itself as an MCP server AND accepts A2A (Agent-to-Agent) calls:

```bash
# Any MCP client (Claude Code, Codex, etc.)
mcp connect https://127.0.0.1:6856/mcp

# OpenAI Agents SDK (A2A)
POST /agent/a2a/v1/tasks/send
{"message": {"role": "user", "parts": [{"text": "your query"}]}}

# OpenAI-compatible (any SDK)
from openai import OpenAI
client = OpenAI(base_url="https://127.0.0.1:6856/v1", api_key="local")
client.chat.completions.create(model="mullm-auto", messages=[...])
```
