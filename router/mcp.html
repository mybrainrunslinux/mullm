MCP — Model Context Protocol

muLLM exposes its routing pipeline as MCP tools, allowing any MCP-compatible client (Claude Code, Cursor, custom agents) to use muLLM for cost-optimized AI queries.

MCP Client → JSON-RPC 2.0 → muLLM MCP Server → classify → route → Cheapest Model

Available MCP Tools

mullm_query
Route an AI query through the cost-optimized pipeline. Returns response from the cheapest capable model.
params: content (string, required), skip_cache (bool), force_tier (string)
mullm_split
Decompose a multi-part query and route each sub-task to the cheapest appropriate tier.
params: content (string, required)
mullm_budget
Get current budget and savings counters.
params: none
mullm_classify
Classify a prompt without executing it. Returns category, complexity, freshness, and suggested tier.
params: content (string, required)
mullm_budget
Return current budget counters and spend-limit state.
params: none
mullm_system
Return CPU, RAM, GPU, VRAM, and Ollama status.
params: none

MCP tool call

pythonimport httpx

client = httpx.Client(base_url="https://localhost:6856", verify=False)

# List available tools
tools = client.get("/mcp/tools").json()
for tool in tools["tools"]:
    print(f"  {tool['name']}: {tool['description']}")

# Call a tool via MCP protocol
r = client.post("/mcp/call", json={
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
        "name": "mullm_query",
        "arguments": {"content": "Explain async/await"}
    }
})
print(r.json())

Streaming (SSE)

pythonimport httpx

with httpx.stream("GET", "https://localhost:6856/query/stream",
                   params={"q": "Write a poem about code"},
                   verify=False) as r:
    for line in r.iter_lines():
        if line.startswith("data: "):
            chunk = line[6:]
            if chunk == "[DONE]":
                break
            print(chunk, end="", flush=True)

JSON-RPC 2.0 Protocol

All MCP communication follows the JSON-RPC 2.0 specification.

Request
{"jsonrpc":"2.0", "id":1, "method":"tools/call", "params":{...}}

Response (success)
{"jsonrpc":"2.0", "id":1, "result":{...}}

Response (error)
{"jsonrpc":"2.0", "id":1, "error":{"code":-32601, "message":"Method not found"}}

Error Codes

reference-32700  Parse error       Invalid JSON
-32600  Invalid request   Missing required fields
-32601  Method not found  Unknown tool/method
-32602  Invalid params    Wrong argument types
-32603  Internal error    Server-side failure
