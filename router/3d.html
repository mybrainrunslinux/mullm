Input: Text or Image

Text-to-3D: Describe what you want — "a medieval longsword with golden crossguard". Works with both local (ComfyUI) and cloud (Meshy) pipelines.

Image-to-3D: Upload or paste an image URL. The model extracts depth and shape to build a mesh. Meshy supports this directly; ComfyUI uses CLIP vision + Hunyuan3Dv2.

Multi-object: Ask for "three swords and a kraken" — muLLM splits the prompt and generates each object in parallel.

Classify & Route (muLLM)

muLLM's classifier analyzes your prompt complexity (1-4 scale) and picks the cheapest capable pipeline:

  • Simple objects (sword, chair, tree) → ComfyUI local ($0) on the RTX 5090
  • Complex/organic (dragon, character, detailed scene) → Meshy cloud (~$0.10) as escalation
  • Procedural (basic shapes, crystals) → Three.js procedural ($0)

You can override the auto-routing with the "Via" dropdown in the generate form.

Mesh Generation

ComfyUI (local, $0): Uses Hunyuan3Dv2 on the RTX 5090. Text → CLIP vision → 3D voxel → mesh via VoxelToMesh. Supports text-to-3D and image-to-3D. Output is GLB via SaveGLB node. ~30-90 seconds depending on complexity.

Meshy API (cloud, ~$0.10): Commercial text-to-3D and image-to-3D service. Handles complex organic shapes well. Preview mode (~1 min), refine mode (~3 min). GLB download on completion.

Both pipelines output standard GLB files. The router escalates to Meshy only when ComfyUI isn't running or for high-complexity prompts.

Texture Refinement (Optional)

After mesh generation from either pipeline, you can optionally run a texture pass through ComfyUI's SDXL pipeline on the 5090:

  • UV unwrap the generated mesh
  • SDXL inpaint generates high-res textures matching your prompt
  • PBR maps (albedo, normal, roughness) for realistic materials

This works for meshes from both ComfyUI and Meshy — the texture pass is always local ($0). Run the texture workspace after generation when you want an explicit material refinement pass.

Export & Storage

Generated models are saved as GLB files to assets/3d/ with a sidecar JSON containing metadata (source, prompt, timestamp, cost).

Cloud-generated models (Meshy) are automatically downloaded and stored locally. All assets are served via the muLLM static file server.

3D Preview

The gallery shows all assets with Three.js orbit viewers. Click any card to open a full-screen viewer with orbit controls, zoom, and download.

Assets from any source (ComfyUI, Meshy, manual drop) appear automatically. Large files (50-100MB+) may take a moment to load.
