Architecture

Three tiers. One goal: $0.

Every query cascades through cost tiers, stopping the moment a tier can answer confidently.

Local First

Groundtruth pattern matching answers deterministic questions in under 1ms — zero AI, zero cost. A local 30B model handles everything else that doesn't need the cloud. No round-trip. No API key consumed.

88% of all queries handled free

Cache Smart

ChromaDB semantic cache finds near-duplicate queries with cosine similarity. 70% hit rate on organic usage. The cache learns your usage patterns — it gets smarter every day without any configuration.

70% hit rate on repeat usage

Cloud Only When Needed

When local and cache can't answer, the router picks the cheapest cloud model capable of the task — Gemini Flash for simple reasoning, GPT-4o only for genuinely hard work. No vendor lock-in.

~12% of queries reach cloud

No GPU Required

50–70% savings even on a laptop.

The local AI tier needs a GPU. But two of the four routing tiers are CPU-only, and smart cloud routing saves money on any hardware.

Groundtruth answers common questions in under 1ms without touching any model. The semantic cache returns prior answers for free. And when you do reach cloud, muLLM picks Gemini Flash ($0.075/M tokens) over GPT-4o ($5/M) whenever the task allows it.

50–70% estimated cloud savings
on a GPU-free machine

Tier 0: Groundtruth

12.7% of queries answered by regex pattern matching. HTTP status codes, git commands, Big-O notation — zero AI, <1ms, zero cost. Works on any hardware.

Tier 1: Semantic Cache

ChromaDB runs on CPU. Every cached query is served free forever. Warm up the cache once, save money on every repeat query permanently.

Smart Cloud Routing

When cloud is needed, the DeBERTa classifier picks the cheapest sufficient model. Simple tasks go to Gemini Flash — 40–60% cheaper than GPT-4o on those workloads.
