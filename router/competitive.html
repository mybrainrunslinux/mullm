Inference Backend Comparison — RTX 5090 · qwen3-coder

muLLM is a routing layer, not an inference engine. Tok/s is determined by the backend you choose. muLLM adds ≤1.8ms routing overhead per query — but routes 93% of queries to groundtruth or cache at $0.00, so average effective latency is lower than running any backend alone.
