Diagnosis Tips
Top 5 Event Loop Blockers
1. Synchronous sleep / time.sleep()
Blocks the entire event loop thread. Use await asyncio.sleep(n) instead.
2. Blocking file I/O
open() + read() in an async function freezes uvicorn. Use asyncio.to_thread() or aiofiles.
3. CPU-bound loops
Heavy scoring / embedding / parsing blocks yielding. Use loop.run_in_executor(None, fn) or a process pool.
4. Synchronous HTTP (requests lib)
requests.get() inside an async route — use httpx.AsyncClient or aiohttp.
5. subprocess.run() without executor
Blocks the loop. Wrap: await asyncio.create_subprocess_exec(...) or push to run_in_executor.
ASYNCIO ARCHITECTURE
uvicorn ─── manages ───> event loop
│
schedules coroutines (await points)
│
if coroutine blocks → ALL requests stall

Fix: await asyncio.to_thread(sync_fn) offloads to thread pool, keeping the loop free to process incoming requests.
