Local-first cost-aware LLM routing

Use the right model only when the work actually needs it.

muLLM routes simple queries to local models, cache, and groundtruth first, then escalates to cloud models only when complexity or policy requires it.

Download View source

Private by default

Local routing, local cache, local setup, and explicit cloud provider toggles.

Budget guarded

Per-query estimates, hard caps, cancellation, and audit events are first-class surfaces.

Modular

Core router stays small. Studio, benchmarks, and coding orchestration are opt-in modules.
